# Surface: Profit dashboard app (all six tabs)

Mode: Operate. Audience: solo Shopee seller checking real profit after month end, laptop first, phone second. Task: upload Order, Income, optional Ads files, fill HPP, read the verdict, act on ranked fixes. Constraints: Bahasa Indonesia, Rupiah formatting, all processing in the browser, sample data labelled "Data contoh". Build path: code-led. Roll ran degraded (no challengers, no quality-bar boards); user chose Nota Rangkap from the presented hand.

## Direction contract

THESIS: Every rupiah shows the paper it came from. Refuses the category default of anonymous KPI tiles with no provenance.

OWN-WORLD: The three-ply carbon receipt book. Carbon-ink blue (#1E2A78) rail and primary ink; ply colours as source codes: Order white, Income pink (#F6D3DD), Iklan yellow (#F6E59A), HPP pale blue (#DCE3F7). Cool blue-tinted ground. Public Sans, tabular numerals. Loss red #B3123A, gain green #15703F, only where they carry meaning.

STORY: The seller sees whether they made money, why, and which file each number came from, then opens the rows behind any figure and goes to the ranked fixes.

FIRST VIEWPORT: Left carbon-blue rail with six numbered steps and the stacked file plies (rows per file). Main: title + month select; verdict card (Profit real big, margin, cause sentence, source chips) beside the three diagnoses; below, the "Dari omzet sampai profit" row of ply-coloured stage cards.

FORM: Standard web app shell (side rail, tabs, tables, selects). Signature move: ply provenance, a stage card or figure opens the rows that produced it, tinted in its ply colour. Position 4 of the grounded list; seed: seed:65fa43c149537a4a

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
